Curriculum Roadmap

Interactive Syllabus

Explore what you will learn week by week

  • Introduction
  • VS Code Setup & Essential Extensions (Live Server)
  • HTML Document Anatomy (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
  • Headings (`<h1>` to `<h6>`), Paragraphs (`<p>`), Formatting Tags
  • Creating Hyperlinks (`<a>`), Images (`<img>`), and Paths
  • Ordered & Unordered Lists (`<ul>`, `<ol>`, `<li>`)
  • Building User Forms (`<form>`, `<input>`, `<label>`, `<button>`)
  • Input types (Text, Password, Email, Radio, Checkbox, Select)
  • Form Validation Attributes (`required`, `placeholder`, `pattern`)
  • Creating Data Tables (`<table>`, `<tr>`, `<td>`, `<th>`)
  • Semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
  • Introduction to CSS: Inline, Internal & External Stylesheets
  • CSS Selectors (Tag, Class, ID, Grouping & Pseudo-classes)
  • Color Systems (HEX, RGB, HSL) & Google Fonts Integration
  • CSS Box Model: Margins, Padding, Borders & Box-Sizing
  • Styling Buttons, Links, Hover States & Transitions
  • Display Property (`block`, `inline`, `inline-block`, `none`)
  • CSS Position (`static`, `relative`, `absolute`, `fixed`, `sticky`)
  • Mastering CSS Flexbox (Flex Container, Justify-Content, Align-Items)
  • CSS Grid Basics for Card Grids & Complex Page Structures
  • Shadows, Gradient Backgrounds & Rounded Border Radius
  • Responsive Web Design principles (Mobile-first approach)
  • CSS Media Queries (`@media screen and (max-width: ... )`)
  • Building 1 Live Portfolio Website from scratch
  • Career Guidance, Resume Building & Doubts Clearing Session
